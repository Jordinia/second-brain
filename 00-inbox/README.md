# 00-inbox: Capture & Intake

Welcome to your inbox. This folder is the low-friction landing zone for unformatted thoughts, quick captures, audio transcripts, and drafts suggested by AI agents.

## Subfolders
- `quick-capture/`: Temporary notes created from mobile or desktop shortcuts.
- `agent-drafts/`: Draft notes proposed by autonomous AI agents awaiting your review.

## Triage Habit
Aim to process notes in this directory regularly:
1. **Actionable?** $\rightarrow$ Convert to a project task or move to `10-projects/`.
2. **Evergreen insight?** $\rightarrow$ Summarize into an atomic concept note in `30-knowledge/`.
3. **Reference procedure?** $\rightarrow$ Format as an SOP in `50-playbooks/`.
4. **Transient scratchpad?** $\rightarrow$ Append to today's daily log in `01-daily/` and discard the raw note.
