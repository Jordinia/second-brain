# 30-knowledge: Evergreen Knowledge Base

This folder is the core intellectual library of your vault. It stores atomic concept notes, literature reviews, scientific models, and learning notes.

## Note Categories
- **Concepts (`KB-`)**: Atomic notes explaining a single mental model, theory, or technical mechanism (`templates/concept.md`).
- **Literature Notes (`LIT-`)**: Deep reviews and executive summaries of academic papers, books, or articles (`templates/literature-note.md`).
- **Learning Notes (`LRN-`)**: Course lectures, webinars, and tutorial summaries (`templates/learning-note.md`).
- **Experiments (`EXP-`)**: Technical benchmarks and experimental logs (`templates/experiment.md`).

## Linking Principle
Notes here should be heavily interconnected via wikilinks (`[[Concept Name]]`), forming an associative semantic web.
