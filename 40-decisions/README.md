# 40-decisions: Architecture Decision Records (ADRs)

Architecture Decision Records document significant architectural, technical, or research decisions along with the context, options considered, and trade-offs accepted.

## Structure of an ADR
Use `templates/decision.md`:
- **Context & Problem Statement**: What forces drove this decision?
- **Considered Options**: What alternatives were evaluated?
- **Decision Outcome**: What was chosen, and why?
- **Consequences**: Positive benefits and accepted drawbacks/risks.

## Naming
Name files descriptively, e.g.:
- `decision-use-postgresql.md`
- `ADR-2026-0001-adopt-ros2-humble.md`
