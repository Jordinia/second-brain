# 10-projects: Active Outcomes & Initiatives

Projects are finite efforts with specific deliverables and a defined deadline or completion condition.

## Creating a Project
Use `templates/project.md` to scaffold a project charter:
- Clearly articulate the **Objective** and **Scope Boundaries**.
- Define discrete, verifiable **Milestones**.
- Maintain links to related architecture decisions (`40-decisions/`) and technical concepts (`30-knowledge/`).

## Archiving
When a project reaches completion or is indefinitely cancelled, move its folder or note to `90-archives/`.
