# assets: Attachments & Media Policy

This folder stores embedded diagrams, system flowcharts, and documentation screenshots.

## Asset Invariants
1. **Lightweight Only**: Individual files should remain under **10MB**.
2. **No Bulky Datasets or Binaries**: Never commit video captures, raw sensor logs, model weights, or compiled binaries here. Store heavy assets in external cloud storage or network shares.
3. **Standard Git Tracking**: All assets in this repository are tracked via standard Git (no Git LFS is required in this template).
