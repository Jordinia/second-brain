# 50-playbooks: Standard Operating Procedures (SOPs)

Playbooks are verified, repeatable checklists and operational guides. If you perform a procedure more than twice, author a playbook.

## Characteristics of a Good Playbook
- **Concrete Prerequisites**: Tooling, permissions, and initial state required before starting.
- **Ordered Execution Ladder**: Step-by-step commands or actions.
- **Verification Gates**: How to confirm that each step succeeded.
- **Rollback Procedure**: What to do if something fails midway.

- `academic-research-workflow.md`: Literature triage, active reading, and synthesis procedure.
