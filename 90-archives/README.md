# 90-archives: Cold Storage & Historical Records

The archive is the final resting place for notes that are no longer actively maintained but retain historical reference value.

## When to Move Notes Here
- **Completed Projects**: Move project charters and deliverable logs when milestones are done.
- **Superseded Decisions**: When an ADR is replaced by a newer decision.
- **Deprecated Playbooks**: Procedures for hardware or software no longer in active use.

## Invariant
Never permanently delete knowledge notes that have incoming wikilinks. Moving them to `90-archives/` preserves backlink integrity while decluttering active folders.
