# 01-daily: Chronological Daily Logs

This folder stores your chronological daily notes, formatted as `YYYY-MM-DD.md`.

## Automatic Creation
Obsidian's native **Daily Notes** plugin is configured to create notes here automatically using `templates/daily.md`.

## Sections Included
- **Top 3 Priorities**: Focus goals for the morning.
- **Active Focus & Tasks**: Progress updates on current projects and research.
- **Chores & Life Admin**: Errands, maintenance, and reminders.
- **Food & Wellness**: Meal tracking, nutrition, and exercise.
- **Financial Log**: Daily realization expenses.
- **Scratchpad**: Rapid thoughts and working notes throughout the day.
